# MathGen CBT

> Advanced Mathematics Question Generator for CBT/AKM with LaTeX support and template export.

## At a glance

| Field | Value |
|---|---|
| Product ID | `ASF-CBT` |
| Status | Prototype stage - founder-driven build, unpublished |
| Delivery | Self-hosted web app |
| Tech stack | React + TypeScript + Vite + Tailwind + Node/Express + @google/genai + Motion + Lucide React |
| Authentication | Server-side Gemini API via env (GEMINI_API_KEY) |

## What it does

This is an AI-assisted application generated and assembled by the founder using the ASF workflow. It integrates a browser UI with a server-side AI call (Google Gemini) to perform its core task. See the module list below for the concrete interface surface present in this repository.

## Getting started

```bash
npm install
npm run dev
```
